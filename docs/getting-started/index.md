# Getting started

`distribution.yaml` names this profile `cyber-au`. It requires Hermes `>=0.22.2` and is under the Apache License 2.0.

A step-by-step quick start is not in this checkout. Install and update behaviour that has been checked against Hermes source is in [Hermes structure](../research/hermes-structure.md).

When a connector needs a credential, it reads that value from the profile `.env` with a `${VAR}` placeholder. This site does not include keys.
