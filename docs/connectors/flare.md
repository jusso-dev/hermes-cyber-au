## Authentication

`FLARE_API_KEY` (raw `Authorization` header) is exchanged at `POST /tokens/generate` for a bearer token that lasts 1 hour. Optional `FLARE_TENANT_ID` selects the tenant. Neither value is logged.

## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `FLARE_API_KEY=${FLARE_API_KEY}`.

Server manifest `env` entry: `FLARE_TENANT_ID=${FLARE_TENANT_ID}`.

Server manifest `required_env`: `FLARE_API_KEY`.

| Variable | Kind | Server `env` | `required_env` | Read in connector |
|---|---|---|---|---|
| `FLARE_API_KEY` | credential | yes | yes | not read in connector source |
| `FLARE_TENANT_ID` | credential | yes | no | not read in connector source |
| `CYBERAU_FLARE_SCHEMA_FIXTURE` | runtime | no | no | `lookup` |

`FLARE_API_KEY` is optional in `SOURCE.md`. `mcp/servers.yaml` lists it under `required_env`.

## Rate limits

Search tier, 1 request a second (under the Basic tier of 4 a second). On HTTP 429 `RATELIMIT_REACHED`, wait for `Retry-After` or 10 seconds, then retry once. Global Search remaining is read from `X-Flare-Global-Searches-Remaining`.

## Cache

HTTP cache `ttl` arguments in the connector source.

No `ttl` argument is set in the connector source.

## Terms and attribution

Commercial licence. Session cache for events and credentials. Store event metadata only. No STIX export of Flare content. No sharing outside the profile. Off by default until you set `enabled: true`. Read only: this connector does not create or change identifiers, groups, matching policies or severity rules.

No attribution string is set in the connector source.

## Fallback and fixtures

The fallback ladder is a live fetch, then the connector's own session cache, then unavailable. No snapshot ships with the connector. When the live fetch fails, the key is missing or rejected, or offline mode (`CYBERAU_OFFLINE=1`) is on with no cached copy, every tool returns empty data with a warning that the Flare source is unavailable. An operator may point `CYBERAU_FLARE_FIXTURES` at a directory of saved responses. Answers from it carry a warning that they came from the operator-supplied files, not a live fetch. The synthetic test fixtures live under `tests/fixtures/`. Only the offline schema check (`check_schema` without `live`) reads them, or `CYBERAU_FLARE_SCHEMA_FIXTURE` when set, and it never returns them as data. A live health check never counts fixture data as ok.

## Operator guide

Read-only events and credential counts from the Flare API. The connector ships off until you set `enabled: true` in your profile `config.yaml`. `doctor` lists it as off by default: licence terms (`off (paid, bring your own licence)`).

Bring your own licence. Put `FLARE_API_KEY` in the profile `.env`. A restricted key with Read Tenant permission and an expiry date is the right choice. `FLARE_TENANT_ID` is optional when the key can reach more than one tenant.

Before the first Flare call in a session, state these terms: Commercial licence. Session cache for events and credentials. Store event metadata only. No STIX export of Flare content. No sharing outside the profile.

The connector does not create or change identifiers, groups, matching policies or severity rules. `doctor --premium` lists watchlist entries Flare is not monitoring so you can add them in Flare.

| Tool | What it returns |
|---|---|
| `flare_tenant_exposure` | Events for the tenant's identifiers since a date, mapped to exposure kinds. No credential values. |
| `flare_identifier_events` | Events for one monitored identifier. |
| `flare_identifiers` | Identifiers monitored in the tenant, compared with the local watchlist. |
| `flare_domain_credentials` | Counts of leaked credentials for one watchlist email domain, by source type and imported date. This spends Global Search quota and asks first above the daily count you set. |
| `flare_quota_status` | Global Search searches remaining this month, from the last response header. |

Tenant searches are preferred. `flare_domain_credentials` accepts only a domain in your watchlist `email_domains`, and the daily count and floor are checked before every page of a Global Search. A list Flare returns in more pages than were read comes back with a partial warning. Password and email queries are not tools. A ransomware leak site claim is marked as reported by the vendor, and the briefing says the claim is unconfirmed.

Search calls stay at one request a second. A 429 waits for `Retry-After`, or 10 seconds when that header is absent, then retries once. The API token is refreshed before the one hour expiry and is not logged.

The optional `flare_mcp` entry points at `https://api.flare.io/mcp` (beta), ships disabled, and includes only the published read tools.
