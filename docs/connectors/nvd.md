## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `NVD_API_KEY=${NVD_API_KEY}`.

Server manifest `required_env`: `NVD_API_KEY`.

| Variable | Kind | Server `env` | `required_env` | Read in connector |
|---|---|---|---|---|
| `NVD_API_KEY` | credential | yes | yes | `lookup` |
| `CYBERAU_DATA_DIR` | runtime | no | no | `os.environ.get` |
| `CYBERAU_EGRESS_ALLOWLIST` | runtime | no | no | `os.environ.get` |
| `CYBERAU_NVD_SNAPSHOT` | runtime | no | no | `os.environ.get` |
| `CYBERAU_OFFLINE` | runtime | no | no | `os.environ.get` |

`NVD_API_KEY` is optional in `SOURCE.md`. `mcp/servers.yaml` lists it under `required_env`.

## Rate limits

5 requests per rolling 30 seconds without a key, 50 with a key.

Limiter arguments in the connector source:

| Function | Call | Key | Rate | Burst | Window |
|---|---|---|---|---|---|
| `_fetch` | `HttpClient` |  | `burst / 30` | `burst` | `rolling` |

`_fetch` sets `burst` to `50 if secret else 5`.

## Cache

HTTP cache `ttl` arguments in the connector source.

A `get` call that omits `stale_if_error` uses the shared client default (1 day).

| Function | Call | TTL | Stale if error |
|---|---|---|---|
| `nvd_get_cve` | `_fetch` | `24 * 3600` (1 day) | not set on this call |
| `nvd_search` | `_fetch` | `3600` (1 hour) | not set on this call |
| `nvd_cve_history` | `_fetch` | `24 * 3600` (1 day) | not set on this call |
| `_fetch` | `get` | forwards `ttl` | not set (shared client default 1 day) |
