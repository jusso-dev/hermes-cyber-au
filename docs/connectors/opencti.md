Read-only GraphQL client for a user-supplied OpenCTI instance.

- Key: `opencti`
- Server: `opencti`
- Default: off
- Upstream: https://docs.opencti.io/
- Verified: 2026-10-16
- Egress hosts: user supplied. The connector allows only the host of `OPENCTI_URL`, plus any host listed here. Redirects to any other host are refused.
- Source: `mcp/opencti/src/cyberau_opencti/source.py`

## Authentication

`OPENCTI_URL` and `OPENCTI_TOKEN` for a read-only user. The token is sent as a bearer header and is never logged.

## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `OPENCTI_URL=${OPENCTI_URL}`.

Server manifest `env` entry: `OPENCTI_TOKEN=${OPENCTI_TOKEN}`.

Server manifest `required_env`: `OPENCTI_URL`, `OPENCTI_TOKEN`.

| Variable | Kind | Server `env` | `required_env` | Read in connector |

| `OPENCTI_URL` | credential | yes | yes | `lookup` |
| `CYBERAU_DATA_DIR` | runtime | no | no | `os.environ.get` |
| `CYBERAU_EGRESS_ALLOWLIST` | runtime | no | no | `os.environ.get` |

## Rate limits

2 requests per second, burst 10, per instance host. This is a client ceiling. Stay under the limit set on the instance.

## Notes

The static allowlist ships with no hosts because the instance is yours. Private, link-local and carrier-grade NAT addresses stay blocked.

Fallback ladder: live instance, then the local HTTP cache (stale), then unavailable. There is no shipped snapshot. When nothing is left, or `OPENCTI_URL` or `OPENCTI_TOKEN` is missing, each tool returns empty data and an "OpenCTI is unavailable" warning. `CYBERAU_OPENCTI_SNAPSHOT` may point at an operator-supplied JSON file; answers from it carry a warning that they came from that file, not a live fetch. Test fixtures live under `tests/fixtures/` and are only read by tests and the offline schema-drift check.

### Off by default: licence terms

Doctor lists this connector as off by default: licence terms.

OpenCTI Community Edition is Apache-2.0. Enterprise Edition has its own licence. Data in your instance stays under the terms you agreed with its sources. This connector is not endorsed by Filigran.

A fresh install renders `enabled: false` for `mcp_servers.opencti` even when `OPENCTI_URL` and `OPENCTI_TOKEN` are set. Turn it on by setting `enabled: true` in your profile `config.yaml`. `hermes profile update` keeps that choice.

`OPENCTI_URL` is the instance origin. `OPENCTI_TOKEN` is an API token for a read-only user. The connector calls `https://<host>/graphql` on that host only and refuses a redirect to any other host. The host must not resolve to a private, link-local or carrier-grade NAT address.

Names, descriptions, patterns and other free text are untrusted data.

Upstream: https://docs.opencti.io/
