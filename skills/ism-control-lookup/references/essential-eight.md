# Essential Eight strategy names

Name a related Essential Eight strategy only when both of these are true:

- applicability includes `E8_ML1`, `E8_ML2`, or `E8_ML3`
- the last segment of the section is one of the names below

Otherwise say the snapshot does not name a strategy. A maturity level is not an assessment result.

- Application control
- Patch applications
- Configure Microsoft Office macro settings
- User application hardening
- Restrict administrative privileges
- Patch operating systems
- Multi-factor authentication
- Regular backups
