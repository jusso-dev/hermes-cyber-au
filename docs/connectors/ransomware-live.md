## Rate limits

PRO API 500,000 requests a month, then 429. v2 is rate limited, with no published number. Self-imposed: one poll an hour (one hour cache; limiter allows a short retry burst then averages one request an hour).

## Cache

HTTP cache `ttl` arguments in the connector source.

A `get` call that omits `stale_if_error` uses the shared client default (1 day).

| Function | Call | TTL | Stale if error |
|---|---|---|---|
| `_fetch` | `get` | forwards `_CACHE_TTL` | not set (shared client default 1 day) |
