# MCP tools for Hindsight and the local handoff queue

Generated by `tools/build_connector_docs.py` from `mcp/hindsight/SOURCE.md`, `mcp/hindsight/schema/`, `mcp/servers.yaml` and `feeds/catalogue.yaml`. Do not edit by hand.

MCP tools for Hindsight and the local handoff queue.

- Key: `hindsight`
- Server: `hindsight`
- Default: off
- Upstream: operator-supplied Hindsight server (retain and recall only). Product notes: https://hindsight.vectorize.io
- Verified: 2026-10-17
- Egress hosts: none shipped. The client talks only to the origin of `HINDSIGHT_BASE_URL`, which must be https. Before every request it resolves the host and refuses loopback, link-local, multicast, reserved, IPv4-mapped, and 6to4 addresses, then connects to the address it checked. RFC 1918 and Tailscale addresses are allowed, so a Hindsight server on the homelab LAN or tailnet can be used. It does not follow redirects, so the key is never sent to another host.
- Source: `mcp/hindsight/src/cyberau_hindsight/source.py`

## Authentication

`Authorization: Bearer` from `HINDSIGHT_API_KEY` in the environment. No key is shipped. Requests omit the header when the variable is unset.

## Rate limits

One request per tool call, no client retries, 30 second timeout. No request is made until `HINDSIGHT_BASE_URL` is set.
