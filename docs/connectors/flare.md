## Authentication

`FLARE_API_KEY` (raw `Authorization` header) is exchanged at `POST /tokens/generate` for a bearer token that lasts 1 hour. Optional `FLARE_TENANT_ID` selects the tenant. Neither value is logged.

## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `FLARE_API_KEY=${FLARE_API_KEY}`.

Server manifest `env` entry: `FLARE_TENANT_ID=${FLARE_TENANT_ID}`.

Server manifest `required_env`: `FLARE_API_KEY`.

| Variable | Kind | Server `env` | `required_env` | Read in connector |
|---|---|---|---|---|
| `FLARE_API_KEY` | credential | yes | yes | not read in connector source |
| `FLARE_TENANT_ID` | credential | yes | no | not read in connector source |
| `CYBERAU_FLARE_SCHEMA_FIXTURE` | runtime | no | no | `lookup` |

`FLARE_API_KEY` is optional in `SOURCE.md`. `mcp/servers.yaml` lists it under `required_env`.

## Rate limits

Search tier, 1 request a second (under the Basic tier of 4 a second). On HTTP 429 `RATELIMIT_REACHED`, wait for `Retry-After` or 10 seconds, then retry once. Global Search remaining is read from `X-Flare-Global-Searches-Remaining`.

## Cache

HTTP cache `ttl` arguments in the connector source.

No `ttl` argument is set in the connector source.
