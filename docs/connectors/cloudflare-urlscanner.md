## Authentication

`CLOUDFLARE_URLSCAN_API_TOKEN` (Account > URL Scanner > Edit) and `CLOUDFLARE_ACCOUNT_ID`. The token is sent as a bearer header and is never logged.

## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `CLOUDFLARE_URLSCAN_API_TOKEN=${CLOUDFLARE_URLSCAN_API_TOKEN}`.

Server manifest `env` entry: `CLOUDFLARE_ACCOUNT_ID=${CLOUDFLARE_ACCOUNT_ID}`.

Server manifest `required_env`: `CLOUDFLARE_URLSCAN_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.

## Rate limits

One URL at a time. After a burst of 4, at most one request every 10 seconds, which stays under Cloudflare's client API limits and the 10 to 30 second poll guidance.

## Cache

HTTP cache `ttl` arguments in the connector source.

A `get` call that omits `stale_if_error` uses the shared client default (1 day).

| Function | Call | TTL | Stale if error |
|---|---|---|---|
| `_exchange` | `get` | forwards `ttl` | not set (shared client default 1 day) |

## Terms and attribution

Scans default to Public on Cloudflare's side and appear in the recent scans list, so an internal URL could be published. This connector always sends Unlisted. Submitting a scan needs a person's one-time approval token. Doctor lists this connector as off by default: licence terms (docs/connectors/cloudflare-urlscanner.md).

Attribution returned with each result:

> Cloudflare URL Scanner. Successful scans are kept for 12 months. This connector only submits Unlisted scans, which are left out of the recent scans list. Not affiliated with Cloudflare.
