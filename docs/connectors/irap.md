# IRAP guidance

Read-only quotations from the IRAP pages on cyber.gov.au. This connector does not perform an IRAP assessment and it is not endorsed by ASD.

| Tool | What it returns |
|---|---|
| `irap_search_guidance` | Quoted passages that match a question. If the pages do not answer it, the result says not covered |
| `irap_consumer_checklist` | The consumer guide's preparation checks, each linked to its source paragraph |

Passages are untrusted. Each item carries the source sentence, URL, retrieval date and SHA-256. A failed live fetch retries once, then tries HTTP/1.1 with headers that still name this project, then serves the last stored copy or the shipped snapshot.

The shipped snapshot quotes short passages from the IRAP overview and the July 2025 consumer guide, seen through a search index on 16 October 2026 because cyber.gov.au could not be fetched directly. It includes the guide's baseline preparation checklist. Consumers should still read the current page and talk to their assessor. Nothing here certifies, accredits or approves a system.
