# Code of conduct

Be direct and respectful. Disagree about the controls, not about the person.

Do not harass, threaten, or post someone else's private information. Do not
add secrets, customer names, or live credentials to the repository.

Security reports go through GitHub security advisories. Conduct problems can
be raised in a GitHub issue on this repository.

Maintainers may edit or remove comments and commits that break these rules.
This document is the project's own text.
