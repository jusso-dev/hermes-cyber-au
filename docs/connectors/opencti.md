Read-only GraphQL client for a user-supplied OpenCTI instance.

- Key: `opencti`
- Server: `opencti`
- Default: off
- Upstream: https://docs.opencti.io/
- Verified: 2026-10-16
- Egress hosts: user supplied. The connector allows only the host of `OPENCTI_URL`, plus any host listed here. Redirects to any other host are refused.
- Source: `mcp/opencti/src/cyberau_opencti/source.py`

## Authentication

`OPENCTI_URL` and `OPENCTI_TOKEN` for a read-only user. The token is sent as a bearer header and is never logged.

## Environment variables

Credential values are read from the profile environment. Nothing on this page is a secret value.

Server manifest `env` entry: `OPENCTI_URL=${OPENCTI_URL}`.

Server manifest `env` entry: `OPENCTI_TOKEN=${OPENCTI_TOKEN}`.

Server manifest `required_env`: `OPENCTI_URL`, `OPENCTI_TOKEN`.

| Variable | Kind | Server `env` | `required_env` | Read in connector |
|---|---|---|---|---|
| `OPENCTI_TOKEN` | credential | yes | yes | `lookup` |
| `OPENCTI_URL` | credential | yes | yes | `lookup` |
| `CYBERAU_DATA_DIR` | runtime | no | no | `os.environ.get` |
| `CYBERAU_EGRESS_ALLOWLIST` | runtime | no | no | `os.environ.get` |
| `CYBERAU_OFFLINE` | runtime | no | no | `os.environ.get` |
| `CYBERAU_OPENCTI_SNAPSHOT` | runtime | no | no | `os.environ.get` |

## Rate limits

2 requests per second, burst 10, per instance host. This is a client ceiling. Stay under the limit set on the instance.
